# v0.13.0 — 面板视觉重做（跟随 DSH 皮肤）

起因：用户装上 bloom-theme 皮肤后截图反馈——面板在淡紫壁纸上像「贴了几块白纸」，吸顶条四周的留白和分隔线生硬，整体是通用后台的样子，不是微调能解决的。

约束（不满足就白做）：

- 只消费宿主 `--dsw-alias-*` 与 `--dsw-font/radius/shadow-*`，不写死色相、不引外链字体。换皮肤、切明暗都必须跟着走。
- 不改信息架构：视图、区块顺序、控件职责一概不动，只重做视觉层。
- 不能牺牲可读性：正文 13px/1.7，对比度按 4.5:1 卡；hover 只做颜色/背景过渡，不位移。

## 1. 纸面层级：一层纸，不是一叠白卡

旧做法是 `.panelRoot` 透明、卡片 `bg-layer-1`（明色下纯白），壁纸从卡片缝里透出来，于是「白纸贴壁纸」。

- `.panelRoot` 自己铺 84% 纸色（`--sheet`，`color-mix(bg-base 84%, transparent)`），壁纸透上来一层，整块内容区成为一个面。
- 卡片改 90% `--surface` + 1px `--hairline`，靠明度差和发丝线分层，不靠纯白块。
- 吸顶条用实色 `bg-base` 通栏铺满（负外边距吃掉滚动容器内边距），下缘一条 hairline。不用毛玻璃：半透明会让滚过去的正文从缝里透出来。
- `.panel` 最大宽 1240 → 1160。窄一点在侧栏宽度下更像「一页」，不像「铺满的后台」。

## 2. 去 AI 味的三处删改

- 删 `.panel::before/::after` 两颗琥珀/玫瑰光斑：冷色皮肤下它们是两块脏色，换皮肤也不跟。
- 删 `@keyframes watermarkBreath` 的水印呼吸：常驻动画在阅读界面上只会分神。
- 删 tab 的渐变下划线（`--brand-grad-line`）：选中态改实心墨色（`label-primary` 底 + `label-primary-foreground` 字），一眼可辨，且不依赖彩度。

## 3. 排版：靠字号/字重/字距立骨架

- 页标题 22px / 660 / `-0.024em`，前面加 13px 枢星（四芒星，`currentColor` 跟 accent）——和侧栏图标同母题，是身份标记不是插图。
- 小节标题降到 12px + `letter-spacing .06em` + tertiary：让位给内容，不再和页标题抢层级。
- 正文 13px / 1.7；条目标题与摘要同一行高，长中文段落读起来不发紧。
- 速览数字 22px tabular-nums，与其他数字列（房间计数、表格耗时）统一等宽；数字之间用发丝线分隔，成为一条「数据带」。
- 顶部 scope（私人/共享/项目）改下划线页签：它和下面那排 tab 职责不同（切数据域 vs 切视图），同形会先看混。

## 4. 修掉的四个隐性问题

1. **消费了不存在的令牌**：`--dsw-alias-fill-tsp-secondary`（5 处）、`--dsw-alias-border-soft`（8 处）、`--dsw-alias-bg-card`（1 处）、`--dsw-alias-state-warning-primary`（4 处，真名 `state-warn-primary`）。CSS 变量未定义时整条声明静默失效，边框和底色直接消失——这是「面板发平、没层次」的一部分成因。已全部替换为本地派生令牌。
2. **`:root` 在 CSS Module 里不作用域化**：插件自建的 `--space-*`/`--fs-*` 会全局泄漏，覆盖宿主同名变量。整块挪到 `.panelRoot` 下。
3. **暗色选择器写错**：宿主只认 `body[data-ds-dark-theme]`，没有 `prefers-color-scheme`。房间色相的暗色版从 `@media` 改到 `body[data-ds-dark-theme] .panelRoot`。
4. **吸顶条上方漏正文**：滚动容器的 `padding-top` 属于滚动区，sticky 按 padding 边定位，那道 16px 缝里会漏出滚过的文字。顶部留白从 `.panelRoot` 移到 `.panel`。

## 5. 顺带清掉硬编码色

`spiral.module.css` 的 `--brand-1/2`（已随令牌块删除）与 `SpiralMap.tsx` 里写死的 amber→rose 渐变，改为 `--dsw-alias-brand-primary` 单色 + 透明度收尾。

## 6. 核验方式

桌面端 GUI 的 auth token 由 IPC 发给 Electron 主进程、不落盘，无法用浏览器截真机画面。因此建了静态 harness `.tmp/preview-v3.html`：直接 `<link>` 面板 CSS、内联 bloom lavender 皮肤的明/暗 alias 与壁纸，标记按真实 JSX 结构写。逐屏截图核对了亮/暗、未滚动/滚动、吸顶遮盖四种状态。

## 7. 取舍

- 字体族继续用宿主的：插件里塞自定义字体既违反皮肤约定，也会让中英混排跳字。
- 房间色相保留，但用 `color-mix(oklab, 色相 82%, bg-base)` 与底色混合，亮色下提亮、暗色下压暗，两套主题都不刺眼。
- 未做：布局重排、动效补充、面板以外（侧栏/宿主外壳）的任何样式。
